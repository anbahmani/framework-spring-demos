# Notes Bruno — MCP

Cette démonstration expose le protocole MCP avec Streamable HTTP. Une collection REST Bruno ne réalise pas à elle seule la négociation de session MCP ni la découverte guidée ; utilisez MCP Inspector comme indiqué dans le README du projet. Bruno peut servir à examiner une requête HTTP brute, mais ce n’est pas le parcours pédagogique de cette démo.
