# Cours 08 — Messages JMS

Ouvrir ce dossier comme collection dans Bruno, puis sélectionner l’environnement `local`.

Cette application échange des messages JMS et ne démarre aucun serveur HTTP. Bruno ne peut donc pas appeler ses fonctionnalités. Lancer la démo avec `mvn spring-boot:run` et observer l’envoi puis la réception dans la console.
