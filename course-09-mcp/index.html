Démo — Cours 09 : Exposer un service Spring avec MCP

Le serveur Spring AI expose un outil de recherche utilisateur avec le transport MCP Streamable HTTP.

Lancer

mvn spring-boot:run

Connecter MCP Inspector au serveur Streamable HTTP http://localhost:8080/mcp. L’outil findUserById permet de consulter deux fiches de démonstration sans utiliser de modèle ni de clé d’API.
